# 🍛 Gangapada Dhaba — Official Website

A premium, mobile-first, conversion-optimized website built for **Gangapada Dhaba**, located on NH 5, Gangapada, Khordha, Bhubaneswar, Odisha. 

Designed with a warm, rustic dark-mode aesthetic, this single-page application helps highway travellers and local diners quickly view the menu, get 1-click Google Maps directions, and contact the restaurant directly.

---

## ✨ Key Features

* **Conversion-First Hero & Navigation:** Sticky header and dedicated mobile bottom action bar (`📍 Directions | 📞 Call Now | 🍽️ Menu`) designed for quick tapping on the go.
* **Live Interactive Menu & Category Filtering:** Browse signature items across *Main Course, Biryani, Tandoor, Snacks, Breakfast,* and *Beverages* with a full-menu modal view.
* **Built-In Owner Edit Mode:** Click **"Enable Edit Mode"** on the menu section to directly edit dish names, descriptions, and prices right in the browser without touching code.
* **Masonry Lightbox Gallery:** Categorized visual showcase for dishes, ambience, dining area, and highway location with a full-screen image viewer.
* **NH 5 Traveller Stop Section:** Tailored specifically for highway commuters between Bhubaneswar and Khordha looking for a quick, reliable meal stop.
* **Trust & Social Proof:** Highlights the **3.8 ⭐ (496+ Reviews)** Google rating alongside clearly labeled demo review placeholders ready for authentic customer testimonials.
* **Local SEO Ready:** Optimized meta tags, semantic HTML5 structure, and targeted local keywords for Bhubaneswar/Khordha highway searches.
* **Zero Dependencies:** Built completely in a single, self-contained `index.html` file using clean HTML5, modern CSS3 (glassmorphism, custom variables, responsive grid), and Vanilla JavaScript.

## 🚀 Quick Start & Free Deployment

Because the entire project is contained within a single `index.html` file, no build tools or package managers are required.

### 1. Run Locally
Simply double-click `index.html` to open it in any web browser, or use the **Live Server** extension in VS Code.

### 2. Host for Free (1-Minute Setup)
* **Netlify Drop (Fastest):**
  1. Put `index.html` inside a folder named `gangapada-dhaba`.
  2. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
  3. Drag and drop the folder onto the page to get an instant live link (e.g., `https://gangapada-dhaba.netlify.app`).
* **GitHub Pages:**
  1. Create a new GitHub repository and upload `index.html` and `README.md`.
  2. Go to **Settings > Pages**, select the `main` branch, and click **Save**.
